# TetherMax

Android + Windows için USB üzerinden mobil internet paylaşım motoru.

Hedef: uygulama içi süre sınırı olmayan bağlantı, düşük gecikmeli oyun profili, adaptif bufferbloat yönetimi ve MyPublicWiFi uyumlu akış önceliklendirmesi.

> Uygulama, operatörün tarife/kota kurallarını değiştiremez. Gerçek USB aktarımı ve performans cihaz üzerinde doğrulanmalıdır.

## Geliştirme güvenliği

Geliştirme Codex Cloud ortamında yürütülecek. Yerel bilgisayardaki PdaNet, MyPublicWiFi, rota, DNS ve ağ adaptörlerine açık onay alınmadan dokunulmayacak.
