# TetherMax RC12 art direction

Built-in Imagegen was used for both images, with no external API key.

Concept prompt: exquisite high-fidelity desktop and Android TetherMax interface;
romantic, tender, sophisticated editorial utility; warm ivory, dusty rose,
soft lavender and plum typography; cuddling ivory cats and lavender flowers;
clear native controls, connection state and empty measured-data tiles;
no slogans, marketing paragraphs, fabricated measurements or watermarks.

Production illustration prompt: transparent PNG of two cuddling, sleeping ivory
cats, one with a dusty rose ribbon, lavender sprigs and a few small pink hearts;
delicate watercolor/ink, refined stationery style; full cats visible, wide 3:2
composition, readable at 240×150; no words, panel, border or device.

The concept is a design reference, not a running-app screenshot. The actual
Android app controls PC companion gaming; it does not select Android game EXEs.
The final production poses use a dark gray, brown-eyed cat and a golden yellow,
green-eyed cat, as requested in the follow-up. Sleeping and awake poses are
embedded in both native applications and decoded once at reduced resolution.
Native transitions, breathing and small lavender motion run only while the view
is active and animations are allowed. Buttons and text remain accessible native
controls. The exact prompt set is saved in prompts.md.
